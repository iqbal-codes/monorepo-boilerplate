# AGENTS.md

TypeScript monorepo on Bun workspaces (`@monorepo-boilerplate`). Root scripts live in `package.json`; coding and boundary rules live in [CODING_STANDARDS.md](./CODING_STANDARDS.md), domain terms in [GLOSSARY.md](./GLOSSARY.md), and architectural decisions in [docs/adr/](./docs/adr/).

## Environment & Codegen Gotchas

- `bun install` runs `env-init` (never overwrites existing `.env`) and `varlock codegen`. After editing `.env.schema`, run `bun run env:generate`.
- Varlock owns env loading (`bunfig.toml` sets `env = false`). Run standalone Bun/Node tools from the owning app directory so they load that app's schema.
- `docker-compose.yml` publishes Postgres 18 on fixed port `5432` (one checkout per host). `packages/db/src/migrations/` starts empty, so `bun run db:push` applies schema changes until migration files exist.
- `bun run rename <name>` is the only supported way to change the package scope and project name.
- `packages/db/src/schema/auth.ts` is generated by `bun run auth:generate` and committed — rerun it after changing Better Auth plugins or schema options.
- `bun run db:seed` writes 53 idempotent customers for the reference flow and pagination-boundary verification.

## Verification & Preview

- **Gate:** `bun run check` (`vp fmt` + `vp lint` + `vp run -r check-types`) and `bun run test` (UI + Archon factory unit tests).
- **Preview:** `.archon/ui-preview.sh` starts `apps/web` on a free port in `4100–4199` and prints `URL=` and `PID=`. Pass `--with-api` for full-stack E2E with `apps/server`.

## Reference Flow & Demo Routes

- Keep the Customers Reference Flow (list → drawer form → detail → avatar upload) compiling and working.
- `apps/web/src/routes/_auth/demo/{fields,blocks}` only exhibit blocks and may be deleted with `rm -rf apps/web/src/routes/_auth/demo`.

## Archon Factory & PRs

- `.archon/workflows/factory/` is copied from `~/.archon/factory-pack/`; upsert from that pack rather than hand-editing.
- Branch from `master`. State only checks you executed in PRs and summaries.
